Maki

A Python framework for building multi-agent LLM applications — LLM backends, agents, plugins, workflows, and a distributed layer for serving agents over HTTP.

View on GitHub Read the Docs
Python 3.10+ MIT License 16 built-in plugins Ollama · OpenAI · Anthropic · HuggingFace

What's inside

Everything needed to go from a single LLM call to a fleet of coordinated, tool-using agents — without locking you into one model provider.

🧩

Multiple LLM backends

Ollama (sync, streaming, async, vision), OpenAI (including reasoning models), Anthropic, and direct HuggingFace Transformers — all behind one LLMBackend contract.

🤖

Agent system

Role-based agents with task execution, memory, step-by-step reasoning, and self-correction. AgentManager handles sequential pipelines, collaborative tasks, and dependency-aware workflows.

🔌

Plugin system

16 built-in plugins, loaded on demand and invoked automatically via TOOL: directives or native tool-calling. Fail-closed by design — every plugin explicitly declares what it exposes.

🕸️

Workflow engine

Dependency resolution via topological sort, retry logic, and optional parallel execution — with checkpoint/resume for long-running workflows.

🌐

Distributed layer

maki serve exposes any agent over HTTP via FastAPI; AgentProxy consumes remote agents transparently, with circuit-breaking built in.

🛡️

Security by default

Every outbound HTTP call — backends, proxies, plugins — routes through a hardened, SSRF-protected connector with DNS pinning and typed error classification.

Architecture

Four layers, cleanly separated — the plugin system sits alongside the agent layer rather than inside it.

01

Public API

maki/__init__.py lazily loads exports on first access, keeping optional-dependency import costs out of the hot path.

02

LLM Backends

MakiLLama, MakiOpenAI, MakiAnthropic, MakiOpenRouter, and HFBackend all implement the abstract LLMBackend contract.

03

Agent System

Agent composes PluginHandler and ReasoningEngine mixins; AgentManager orchestrates agents via WorkflowTask and WorkflowState.

04

Distributed Layer

AgentServer (FastAPI) exposes agents over HTTP; AgentProxy is a remote-agent client with circuit-breaking; DistributedAgentManager mixes local and remote agents.

∞

Infrastructure

Connector (SSRF-protected HTTP with connect-time IP pinning), shared data classes, typed exceptions, runtime config, and structured logging — used by every layer above.

Built-in plugins

Loaded on demand, gated by an explicit ALLOWED_METHODS whitelist per plugin — nothing is reachable from an LLM tool call unless it's named there.

Install

Core install is intentionally small — just requests, httpx, and python-dotenv. Everything else is an opt-in extra.

# clone and install from source
git clone https://github.com/BowlOfData/maki.git
cd maki
pip install -e .

# with an extra, e.g. distributed serving + dev tooling
pip install -e ".[dev,distributed]"

# everything
pip install -e ".[all]"
